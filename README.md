# ✈️ Travaura

### 🌍 Your Travel Companion for Discovering Amazing Places

**Travaura** is a travel-focused web application designed to help users explore destinations, discover interesting places, and plan their travel experience through a simple and user-friendly interface.

The project provides dedicated pages for the main travel experience and suggested destinations, making it easier for users to discover places that match their interests.

---

## ✨ Features

* 🌍 **Explore Destinations**
  Discover travel destinations through an interactive web interface.

* 📍 **Suggested Places**
  Browse recommended places and discover new destinations.

* 🧭 **Travel-Focused Interface**
  Simple and intuitive navigation designed for travelers.

* 📱 **Responsive Web Experience**
  Designed to provide a convenient experience across different screen sizes.

* ⚡ **Fast & Lightweight**
  Built as a lightweight web application using web technologies.

* 🔄 **Continuous Development**
  The project can be extended with additional travel, recommendation, and booking features.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/kandivalasamounika/Travaura.git
```

### 2. Open the project

```bash
cd Travaura
```

### 3. Run the application

Since Travaura is a web project, you can open `index.html` directly in your browser.

For a better development experience, you can use **Visual Studio Code** with the **Live Server** extension.

### Using Live Server

1. Open the project folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. The application will open in your browser.
